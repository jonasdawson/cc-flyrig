### PreToolUse
  PreToolUse
  Input to command is JSON of tool call arguments.
  Exit code 0 - stdout/stderr not shown
  Exit code 2 - show stderr to model and block tool call
  Other exit codes - show stderr to user only but continue with tool call

  No hooks for this event yet
  To add hooks, edit settings.json directly or ask Claude

### PostToolBatch
  PostToolBatch

### DirectoryAdded
  DirectoryAdded
  Fires after /add-dir or the register_repo_root SDK control request registers a new working directory, after the sandbox configuration has been refreshed — so sandboxed tools and permission state
  already see the new directory (hook commands themselves run unsandboxed).
  Input to command is JSON with directory (absolute path) and source ("slash_command" or "register_repo_root").
  Exit code 0 - command completes successfully
  Other exit codes - stderr is debug-logged on both paths; for /add-dir, a failure count is summarized to Claude and hook systemMessage output reaches Claude as bounded context; for
  register_repo_root, everything is debug-logged only

  No hooks for this event yet
  To add hooks, edit settings.json directly or ask Claude
